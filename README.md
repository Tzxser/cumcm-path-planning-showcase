# 数学建模路径规划与定位算法展示

本仓库用于张轩松的实习申请，选取 2026 年全国大学生数学建模竞赛 B 题团队项目中的编程与算法实现。本人担任团队编程手，结合 GPT 辅助开发。公开范围为算法源码及使用合成案例的离线演示，不包含团队最终论文、赛题附件、平台程序、队号、Robot ID、正式日志或其他队员个人资料。

## 实现内容

- Q3：七点发现网、定位区域收缩、开放路径最近邻与 2-opt 调整。
- Q4：22 点发现网、连续区域覆盖检查、入口—服务—出口服务弧与有限中断重规划。
- 请求与状态记录、确定性离线案例，以及正式结果和离线结果的口径区分。

这些是数学建模和模拟场景的算法经验，不代表已在无人机、ROS 或真实飞控上部署。

## 阅读入口

- `algorithms/Q3/routing.py`：路径排序和绕行成本。
- `algorithms/Q3/localization.py`：定位过程。
- `algorithms/Q4/candidates/q4_x41.py`：所选组合策略。
- `algorithms/Q4/interval_cover.py`、`rotatable_net.py`：覆盖与发现网构造。
- `algorithms/Q4/service_arcs_round3.py`：服务弧与局部任务安排。
- `algorithms/offline_sim/simulator.py`：基于建模假设生成的离线案例。

## 离线演示

使用 Python 3.10 或以上，所选演示仅使用标准库。以下入口禁止网络连接，输出写入本仓库 `runs/`：

```powershell
python run_offline.py --question 3
python run_offline.py --question 4
```

默认随机种子为 20260912，可用 `--seed` 选择其他合成案例。离线虚拟耗时属于当前模型假设，不能当作官方模拟器成绩、真实机器人性能或未来案例保证。
